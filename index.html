개인용 유튜브 업로드 도구 · A personal YouTube upload tool

무엇을 하나요

제가 직접 운영하는 유튜브 채널에, 제 컴퓨터에서 만든 음악 플레이리스트 영상을 올리는 개인용 프로그램이에요. 영상 업로드, 제목·설명글·태그 설정, 예약 공개, 재생목록에 추가하는 데에만 유튜브 API 를 써요.

This is a personal desktop tool that uploads music playlist videos, made on my own computer, to YouTube channels that I own and operate. It uses the YouTube Data API only to upload videos, set their title, description and tags, schedule publishing, and add them to playlists.

누가 쓰나요

이 앱은 공개 서비스가 아니에요. 채널 주인인 저만 제 채널에 로그인해서 써요.

This is not a public service. It is used only by me, the channel owner, on my own channels.
